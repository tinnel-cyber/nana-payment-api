Signatures Webhook & Anti-Rejeu HMAC-SHA256

Vérification cryptographique en Node.js et PHP avec fenêtre stricte de 300 secondes.

const crypto = require('crypto');

function verifyNanaSwitchWebhook(rawBody, signatureHeader, secretKey) {
  const parts = Object.fromEntries(signatureHeader.split(',').map(p => p.split('=')));
  const timestamp = parseInt(parts.t, 10);
  const signature = parts.v1;

  // 1. Fenêtre anti-rejeu 5 minutes
  if (Math.abs(Date.now() / 1000 - timestamp) > 300) {
    throw new Error('Timestamp expiré');
  }

  // 2. Calcul du HMAC sur "${timestamp}.${rawBody}"
  const expected = crypto
    .createHmac('sha256', secretKey)
    .update(`${timestamp}.${rawBody}`)
    .digest('hex');

  // 3. Comparaison sécurisée timingSafeEqual
  return crypto.timingSafeEqual(Buffer.from(signature, 'utf8'), Buffer.from(expected, 'utf8'));
}
SECTION 5 • PROMPT 5

Modèle Hybride B2B : Agrégé vs SaaS BYOK

Deux modes de fonctionnement adaptés à chaque profil d'entreprise.

Mode Simplifié (AGREGATED)

Encaissement automatique via le compte maître régulé NanaSwitch. Aucune passerelle requise. Marge retenue : +1.5% de frais de switch à la source.

Mode Développeur SaaS (BYOK)

Injection de vos propres clés SasPay ou Sebpay. 0% de commission de switch. Facturation à l'usage SaaS : 0,02 XOF par requête débité de votre solde de crédits API.

Version 1.0.0 • Conforme HPOS & WordPress 5.8 à 6.7+

📦 Télécharger nanaswitch-gateway.zip

Guide d'installation rapide :

  1. Dans WordPress, rendez-vous dans Extensions > Ajouter > Téléverser.
  2. Sélectionnez l'archive nanaswitch-gateway.zip et cliquez sur Installer.
  3. Activez l'extension puis ouvrez WooCommerce > Réglages > Paiements > NanaSwitch Gateway.
  4. Renseignez votre Public Key, Secret Key et Secret Webhook générés sur la console.
SECTION 8 • PROMPT 8

Codes d'Erreur HTTP & Matrice de Dépannage

Guide de résolution pas à pas pour les intégrateurs.

400 Bad Request Paramètres manquants ou payload JSON invalide

👉 Vérifiez les champs amount, currency (XOF), customer.phone et orderId.

401 Unauthorized Clé secrète ns_live_sk_* invalide ou absente

👉 Vérifiez le header Authorization: Bearer ns_live_sk_... sans espaces superflus.

402 Payment Required Solde de crédits API SaaS épuisé en mode BYOK

👉 Rechargez votre portefeuille de crédits API depuis l'espace Développeur.

403 Forbidden Plafond mensuel KYC atteint (1M ou 5M XOF)

👉 Soumettez les pièces RCCM/IFU pour passer en compte Entreprise.
