# NaNaSwitch Cloud — Smart API Router & Connector
## Extension Chrome / Edge / Brave (Manifest V3)

Cette extension permet de relier vos boutiques, outils de vente (WhatsApp Web, CRM, ERP) et applications externes directement au Routeur Cloud Intelligent de **NaNaSwitch Cloud**.

### 🛡️ Sécurité Zero-Trust :
- Aucun accès direct à la base de données mère.
- Vos identifiants de paiement (SebPay, CinetPay, PayDunya, Stripe) restent strictement isolés dans le Coffre Cloud chiffré AES-256.
- L'extension s'authentifie uniquement par jeton Cloud `nana_sw_live_...`.

### 🚀 Installation en 3 Étapes Faciles :
1. Ouvrez Google Chrome ou Microsoft Edge et accédez à : `chrome://extensions/`
2. Activez le **Mode Développeur** (interrupteur en haut à droite).
3. Cliquez sur **"Charger l'extension non empaquetée"** et sélectionnez le dossier `nana-switch-extension`.
4. Cliquez sur l'icône de l'extension dans votre barre d'outils et collez votre clé d'accès Cloud générée dans la console (`/nana-switch/security`).
